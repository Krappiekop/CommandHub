# Notities per feature

Elke feature heeft één notitie, onafhankelijk van de dag of bouwvolgorde. Een feature mag meerdere werksessies beslaan.

- Featurespecificatie en actuele checklist: docs/features/.
- Uitleg, ervaringen en historie: het bijbehorende bestand hier.
- Belangrijke blijvende ontwerpkeuze: docs/beslissingen/.
- Korte overdracht voor een volgende sessie of AI: docs/voortgang.md.

Voeg nieuwe werksessies als gedateerde sectie toe aan dezelfde notitie. Kopieer geen actuele todo-lijst naar het logboek. Beschrijf wat werkt met bewijs, niet alleen wat de bedoeling is.

Gebruik gewone relatieve Markdown-links: die werken op GitHub en in Obsidian. Open de repository als vault of gebruik deze notities in je bestaande vault. Commit geen lokale .obsidian-instellingen.
