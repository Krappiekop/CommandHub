# Configuratievoorbeelden

In F02 komt hier het definitieve JSON-voorbeeld. De basis leest nog geen configuratiebestand.

Voorlopig voorbeeld volgens de opdracht:

```json
{
  "tools": [
    {
      "name": "git_version",
      "description": "Show the installed Git version",
      "command": "git",
      "arguments": ["--version"],
      "parameters": [],
      "timeout": 5000
    }
  ]
}
```

Dit voorbeeld is ontwerpinput, nog geen geïmplementeerd of volledig beveiligd schema. Voeg uitvoer- en capaciteitsgrenzen en het executable-/padbeleid toe vóór generieke uitvoering.
